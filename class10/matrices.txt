1. LIST KYA HOTI HAI?


List ek container hai jisme hum multiple values store kar sakte hain.
Example: agar humein 5 students ke marks store karne hain, toh alag-alag variables banane ke bajaye ek list bana sakte hain.

Example:
marks = [70, 80, 90, 60, 85]

Indexing zero se start hoti hai:
marks[0] = 70
marks[1] = 80
marks[2] = 90

Yaad rakho: agar list mein n elements hain, toh last valid index n-1 hota hai.

while i < n:
Jab tak i, n se chhota hai, loop chalega.

Ek number read kiya, int() se integer banaya aur append() se list mein add kiya.

PART 2 — 2-D MATRICES
============================================================

1. MATRIX KYA HOTI HAI?


Agar data rows aur columns mein arranged ho, jaise spreadsheet ya marksheet, toh hum matrix jaisi structure use karte hain.

Python mein separate built-in matrix type ki zaroorat nahi. Hum list ke andar lists rakhte hain. Isliye ise list of lists kehte hain.

Example:
m = [
    [1, 2, 3],
    [4, 5, 6],
    [7, 8, 9]
]

m[0] -> [1, 2, 3] (first row)
m[1] -> [4, 5, 6] (second row)
m[1][2] -> 6 (second row, third column)
len(m) -> 3 rows
len(m[0]) -> 3 columns

First index row batata hai. Second index column batata hai.

2. MATRIX INPUT LENA

Input:
3 3
1 2 3
4 5 6
7 8 9

Code:
first = input().split()
R = int(first[0])
C = int(first[1])

m = []
i = 0

while i < R:
    parts = input().split()
    row = []
    j = 0

    while j < C:
        row.append(int(parts[j]))
        j += 1

    m.append(row)
    i += 1

print(m)

Output:
[[1, 2, 3], [4, 5, 6], [7, 8, 9]]

EXPLANATION:
R rows ki count hai.
C columns ki count hai.
m = [] empty matrix hai.
Outer while loop har row banata hai.
Har row ke liye row = [] banate hain.
Inner while loop C numbers read karke row mein add karta hai.
Jab row complete ho jaati hai, m.append(row) se matrix mein add karte hain.

IMPORTANT:
j = 0 ko outer loop ke andar likhna zaroori hai, taaki har new row ke liye column counter reset ho.

3. ROW-WISE TRAVERSAL

Code:

while i < R:

Output:
1 2 3 4 5 6 7 8 9

Outer loop rows par chalta hai.
Inner loop current row ke columns par chalta hai.

4. COLUMN-WISE TRAVERSAL

Code:

while j < C:
    i = 0
    while i < R:
        print(m[i][j], end=" ")
        i += 1
    j += 1

Output:
1 4 7 2 5 8 3 6 9

Outer loop columns par chalta hai.
Inner loop current column ki rows par chalta hai.

GOLDEN RULE:
Row-wise: outer i (rows), inner j (columns).
Column-wise: outer j (columns), inner i (rows).
Loop order badalne se traversal order badal jaata hai.

Output:

while d <= R + C - 2:

B10 — SPIRAL TRAVERSAL


Order:
1. Top row: left se right.
2. Right column: top se bottom.
3. Bottom row: right se left.
4. Left column: bottom se top.
Phir boundaries ko andar move karo aur repeat karo.

Code:
top = 0
bottom = R - 1
left = 0
right = C - 1

while top <= bottom and left <= right:

    j = left
    while j <= right:
        print(m[top][j], end=" ")
        j += 1
    top += 1

    i = top
    while i <= bottom:
        print(m[i][right], end=" ")
        i += 1
    right -= 1

    if top <= bottom:
        j = right
        while j >= left:
            print(m[bottom][j], end=" ")
            j -= 1
        bottom -= 1

    if left <= right:
        i = bottom
        while i >= top:
            print(m[i][left], end=" ")
            i -= 1
        left += 1

Output:
1 2 3 6 9 8 7 4 5

BOUNDARIES:
top = current top row
bottom = current bottom row
left = current left column
right = current right column

Har side complete karne ke baad boundary andar move hoti hai.
if conditions important hain, kyunki last mein ek hi row ya column bach sakta hai. Conditions duplicate printing se bachati hain.

B9 — DIAGONAL ZIGZAG TRAVERSAL
============================================================

1. DIAGONAL ZIGZAG TRAVERSAL KA MEANING
------------------------------------------------------------

Diagonal Zigzag Traversal mein hum same anti-diagonals use karte hain jo normal diagonal traversal mein use hoti hain.

Difference sirf direction ka hota hai.

Har alternate diagonal ki traversal direction reverse hoti hai.

Matrix:

1 2 3
4 5 6
7 8 9


Normal Diagonal Traversal:

1 2 4 3 5 7 6 8 9


Diagonal Zigzag Traversal:

1 2 4 7 5 3 6 8 9


------------------------------------------------------------
2. DIAGONAL GROUPS
------------------------------------------------------------

Anti-diagonal identify karne ka rule hai:

d = i + j

Jin cells ka i + j same hota hai, woh same anti-diagonal mein aate hain.


Matrix:

          Column
          0   1   2

Row 0     1   2   3
Row 1     4   5   6
Row 2     7   8   9


Diagonal Groups:

d = 0:
1

d = 1:
2 4

d = 2:
3 5 7

d = 3:
6 8

d = 4:
9


Zigzag Traversal mein order:

d = 0 → 1
d = 1 → 2 4
d = 2 → 7 5 3
d = 3 → 6 8
d = 4 → 9


Final Output:

1 2 4 7 5 3 6 8 9


------------------------------------------------------------
3. ZIGZAG DIRECTION KA LOGIC
------------------------------------------------------------

Direction decide karne ke liye check karte hain:

if d % 2 == 0:

% operator remainder deta hai.

Agar d even hai:

d = 0, 2, 4 ...

Toh traversal ek direction mein hogi.

Agar d odd hai:

d = 1, 3, 5 ...

Toh traversal opposite direction mein hogi.


Is code mein:

Even diagonal → Bottom se Top

Odd diagonal → Top se Bottom


------------------------------------------------------------
4. COLUMN INDEX KA FORMULA
------------------------------------------------------------

Diagonal ka rule hai:

d = i + j

Column index j nikalne ke liye:

j = d - i


Example:

Agar d = 2 hai:

i = 0 → j = 2 → m[0][2] = 3
i = 1 → j = 1 → m[1][1] = 5
i = 2 → j = 0 → m[2][0] = 7


d = 2 diagonal ke elements hain:

3 5 7


Direction ke according ye print ho sakte hain:

3 5 7

Ya reverse direction mein:

7 5 3


------------------------------------------------------------
5. EVEN DIAGONAL TRAVERSAL
------------------------------------------------------------

Code:

if d % 2 == 0:
     i = R-1


    while i >= 0:

        j = d - i

        if 0 <= j < C:
            print(m[i][j], end=" ")

Yahan:

i -= 1

Matlab row index decrease ho raha hai.

Isliye traversal bottom se top ki taraf hoti hai.


Example: d = 2

i = 2 → j = 0 → m[2][0] = 7
i = 1 → j = 1 → m[1][1] = 5

------------------------------------------------------------
IMPORTANT: STARTING VALUE OF i
------------------------------------------------------------

Even aur odd diagonal mein starting value of i alag hoti hai, kyunki humein hamesha diagonal ke ek valid cell se traversal start karna hota hai.


1. EVEN DIAGONAL
------------------------------------------------------------

Code:

i = d if d < R else R - 1


Iska simple meaning:

Agar diagonal number d valid row index ke andar hai, toh i = d se start karo.

Otherwise, last valid row R - 1 se start karo.


Example: 3 x 3 Matrix

Valid row indices:

0, 1, 2


Agar:

d = 2

2 < R (3)

Isliye:

i = 2


Lekin agar:

d = 4

4 < 3 → False

i = 4 invalid row index hoga.

Isliye:

i = R - 1 = 2


SHORT RULE:

Even diagonal mein bottom-most valid row se start karna hai.

Phir:

i -= 1

karke bottom se top move karte hain.


------------------------------------------------------------
2. ODD DIAGONAL
------------------------------------------------------------

Code:

i = 0 if d <= C - 1 else d - (C - 1)


Iska simple meaning:

Agar diagonal top row se start kar sakti hai, toh i = 0 se start karo.

Otherwise, itni rows neeche se start karo jahan column index valid ho.


Example: 3 x 3 Matrix

Valid column indices:

0, 1, 2


Agar:

d = 1

d <= C - 1

1 <= 2 → True

Isliye:

i = 0


Lekin agar:

d = 3

Top row se start karne par:

i = 0

j = d - i

j = 3 - 0 = 3


Lekin column 3 invalid hai.

Isliye:

i = d - (C - 1)

i = 3 - 2

i = 1


Ab:

j = d - i

j = 3 - 1 = 2

Column index valid hai.


SHORT RULE:

Odd diagonal mein top-most valid row se start karna hai.

Phir:

i += 1

karke top se bottom move karte hain.

m = [
    [1, 2, 3],
    [4, 5, 6],
    [7, 8, 9]
]

R = len(m)
C = len(m[0])

d = 0

while d <= R + C - 2:

    if d % 2 == 0:

        i = d if d < R else R - 1

        while i >= 0:

            j = d - i

            if 0 <= j < C:
                print(m[i][j], end=" ")

            i -= 1

    else:

        i = 0 if d <= C - 1 else d - (C - 1)

        while i < R:

            j = d - i

            if 0 <= j < C:
                print(m[i][j], end=" ")

            i += 1

    d += 1

11. COMPLETE CODE
------------------------------------------------------------

m = [
    [1, 2, 3],
    [4, 5, 6],
    [7, 8, 9]
]

R = len(m)
C = len(m[0])

top = 0
bottom = R - 1
left = 0
right = C - 1

while top <= bottom and left <= right:

    # Top Row: Left to Right
    j = left

    while j <= right:
        print(m[top][j], end=" ")
        j += 1

    top += 1


    # Right Column: Top to Bottom
    i = top

    while i <= bottom:
        print(m[i][right], end=" ")
        i += 1

    right -= 1


    # Bottom Row: Right to Left
    if top <= bottom:

        j = right

        while j >= left:
            print(m[bottom][j], end=" ")
            j -= 1

        bottom -= 1


    # Left Column: Bottom to Top
    if left <= right:

        i = bottom

        while i >= top:
            print(m[i][left], end=" ")
            i -= 1

        left += 1
