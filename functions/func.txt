PART 1: WHY DO WE NEED FUNCTIONS?
============================================================

1. INTRODUCTION TO FUNCTIONS

Abhi tak humne Python mein variables, conditions, loops, lists, strings aur mathematical problems solve kiye hain.

Generally hum apna code directly likhte hain:

price = 500
tax = price * 18 / 100
total = price + tax

print(total)

Ab imagine karo ki ek shop mein 100 customers hain aur har customer ke liye same billing calculation karni hai.

Kya hum har customer ke liye same 3-4 lines baar-baar likhenge?

Nahi!

Yahi problem solve karne ke liye FUNCTIONS use hote hain.

Function ek reusable block of code hota hai jo kisi particular task ko perform karta hai.

Ek baar function define kar do aur jab bhi uski zarurat ho, usse call kar sakte ho.

Real-life example:

ATM machine mein withdrawal ka ek fixed process hota hai.

1. Account check karna.
2. Balance check karna.
3. Amount deduct karna.
4. Cash dispense karna.

Ye process ek baar design hota hai, lekin multiple transactions mein reuse hota hai.

Programming mein bhi hum aise hi reusable logic create karte hain.

------------------------------------------------------------
2. CODE REPETITION PROBLEM
------------------------------------------------------------

Suppose humein 3 customers ka final bill calculate karna hai, jismein 18% tax add hota hai.

Code:

price1 = 500
tax1 = price1 * 18 / 100
total1 = price1 + tax1
print("Customer 1 pays:", total1)

price2 = 1200
tax2 = price2 * 18 / 100
total2 = price2 + tax2
print("Customer 2 pays:", total2)

price3 = 750
tax3 = price3 * 18 / 100
total3 = price3 + tax3
print("Customer 3 pays:", total3)

Output:

Customer 1 pays: 590.0
Customer 2 pays: 1416.0
Customer 3 pays: 885.0

Problem kya hai?

1. Same calculation baar-baar likhni pad rahi hai.
2. Code unnecessarily lengthy ho raha hai.
3. Agar tax rate change hua, toh multiple places par changes karne padenge.
4. Agar ek jagah change karna bhool gaye, toh program inconsistent ho jayega.

Is problem ko CODE DUPLICATION kehte hain.

------------------------------------------------------------
3. CAN A LOOP SOLVE THIS PROBLEM?
------------------------------------------------------------

Haan!

Agar same calculation consecutive lines mein repeat ho rahi hai aur different prices ke liye perform karni hai, toh loop use kar sakte hain.

Example:

for price in [500, 1200, 750]:

    tax = price * 18 / 100
    total = price + tax

    print("Pays:", total)

Yahan loop ne repetition remove kar di.

Lekin ek important question hai.

Kya har type ki repetition ko loop se solve kar sakte hain?

Nahi!

Consider karo ki humein 3 different tasks mein prime number checking ka logic use karna hai:

1. 10 se 30 ke beech prime numbers print karna.
2. User ke diye hue number ko prime check karna.
3. User ke number ke baad next prime number find karna.

Teeno tasks mein prime checking ka logic same hai, lekin teeno different places aur different loop structures ke andar hain.

Ek single loop in teeno jagah ke logic ko combine nahi kar sakta.

Yahan FUNCTION ki zarurat hoti hai.

------------------------------------------------------------
4. DRY PRINCIPLE
------------------------------------------------------------

DRY ka full form hai:

DON'T REPEAT YOURSELF

Meaning:

Ek particular logic ko baar-baar alag-alag places par likhne ke bajaye uska ek single source of truth hona chahiye.

Benefits:

1. Code duplication reduce hota hai.
2. Code maintain karna easy hota hai.
3. Changes ek hi place par karne padte hain.
4. Bugs ke chances kam hote hain.
5. Code reusable aur readable banta hai.

IMPORTANT DIFFERENCE:

LOOP:
Same lines ko ek hi place par repeatedly execute karta hai.

FUNCTION:
Logic ko ek naam deta hai, jisse program ke different places se call kar sakte hain.

PART 4: RETURN STATEMENT
============================================================

11. RETURN KYA HOTA HAI?

return statement function se result caller ko wapas bhejne ke liye use hota hai.

Example:

def add(a, b):

    result = a + b

    return result


ans = add(10, 20)

print(ans)

Output:

30

Execution:

1. add(10, 20) call hua.
2. a = 10 aur b = 20.
3. result = 30.
4. return result se 30 caller ko wapas mil gaya.
5. ans = 30 ho gaya.
6. print(ans) ne 30 print kar diya.

IMPORTANT:

return ke baad function immediately terminate ho jata hai.

Example:

def demo():

    print("Start")

    return 100

    print("End")

x = demo()
print(x)

Output:

Start
100

"End" print nahi hoga kyunki return ke baad function execution stop ho chuka hai.

------------------------------------------------------------
12. PRINT VS RETURN
------------------------------------------------------------

Ye functions ka sabse important concept hai.

PRINT:

Output screen par display karta hai.

RETURN:

Value ko function ke caller ke paas bhejta hai, jise program further use kar sakta hai.

Example 1:

def add(a, b):

    print(a + b)


x = add(10, 20)

print("x =", x)

Output:

30
x = None

Kyun?

Kyunki function ne answer print kiya, return nahi kiya.

Python automatically None return karta hai jab function mein explicit return nahi hota.

Example 2:

def add(a, b):

    return a + b


x = add(10, 20)

print("x =", x)

Output:

x = 30

Difference:

First function:
Answer screen par print kiya, lekin caller ko result nahi diya.

Second function:
Answer caller ko return kiya, jise variable mein store kar sakte hain.

IMPORTANT:

Har function jo explicit return nahi karta, woh None return karta hai.

------------------------------------------------------------
13. RETURNING DIFFERENT VALUES
------------------------------------------------------------

Example:

def check_even(n):

    if n % 2 == 0:
        return True

    else:
        return False


result = check_even(10)

print(result)

Output:
True

Is function ko aur simple likh sakte hain:

def check_even(n):
    return n % 2 == 0

Explanation:

n % 2 == 0 ka result already Boolean hota hai.

Isliye directly return kar sakte hain.

------------------------------------------------------------
14. EARLY RETURN
------------------------------------------------------------

Early return ka matlab hai condition satisfy hote hi function se result return kar dena.

Example: Prime Number Checker

def is_prime(n):

    if n < 2:
        return False

    i = 2

    while i * i <= n:

        if n % i == 0:
            return False

        i += 1

    return True


print(is_prime(7))
print(is_prime(10))
print(is_prime(1))

Output:

True
False
False

Explanation:

Step 1:

Agar n < 2 hai, toh immediately False return.

Step 2:

i = 2 se divisors check karna start.

Step 3:

Agar n kisi i se completely divisible hai, toh prime nahi hai.

Immediately False return.

Step 4:

Agar loop complete ho gaya aur koi divisor nahi mila, toh True return.

IMPORTANT:

return sirf loop ko nahi, poore function ko terminate karta hai.

Comparison:

break:
Sirf current loop terminate karta hai.

return:
Poore function ko terminate karta hai.

Flag approach aur early return dono valid techniques hain.

------------------------------------------------------------
15. FUNCTION CALLING INSIDE ANOTHER FUNCTION
------------------------------------------------------------

Ek function ke andar doosra function call kar sakte hain.

Example:

def square(n):
    return n * n


def cube(n):
    return square(n) * n


print(cube(3))

Output:
27

Execution:

cube(3)

square(3) = 9

9 * 3 = 27

Isse code modular aur reusable banta hai.

PART 6: ONE FUNCTION – MULTIPLE DATA TYPES
============================================================

21. PYTHON'S DYNAMIC TYPING

Python mein function parameters ka type pehle se declare karna necessary nahi hota.

Example:

def times(a, b):
    return a * b


print(times(2, 4))
print(times("Ni", 4))
print(times([1, 2], 3))

Output:

8
NiNiNiNi
[1, 2, 1, 2, 1, 2]

Explanation:

First call:

2 * 4 = 8

Second call:

"Ni" * 4 = "NiNiNiNi"

Third call:

[1, 2] * 3 = [1, 2, 1, 2, 1, 2]

Same function, different data types.

Kyun?

Python function definition mein humne type specify nahi kiya.

Jo objects arguments ke form mein aaye, unke supported operations ke according function execute hua.

------------------------------------------------------------
22. OPERATION-BASED THINKING
------------------------------------------------------------

Python ka focus sirf data type par nahi, balki supported operations par bhi hota hai.

Example:

def multiply(a, b):
    return a * b

Ye function un values ke saath work karega jinke liye * operation supported hai.

Lekin:

multiply("Ni", "Ni")

Error:

TypeError

Kyunki string ko string se multiply karna supported nahi hai.

IMPORTANT:

Python mein incorrect type combination ka error function definition ke time zaroori nahi aata.

Error tab aata hai jab problematic call execute hota hai.

Is philosophy ko commonly DUCK TYPING kehte hain.

Simple meaning:

If an object supports the operations required by your code, it can be used.

Comparison:

Statically typed language:
"What type is this variable?"

Python:
"Does this object support the operation I need?"

PART 7: HOW ARGUMENTS TRAVEL
============================================================

23. ARGUMENT PASSING IN PYTHON

Example:

def double(x):

    x = x * 2

    print("Inside:", x)


n = 7

double(n)

print("Outside:", n)

Output:

Inside: 14
Outside: 7

Question:

Function ke andar x ki value 14 ho gayi, lekin n ki value 7 hi kyun hai?

Explanation:

Function call ke time:

x = n

Initially dono names same integer object 7 ko refer karte hain.

But:

x = x * 2

Is operation se 14 ka new integer object create hota hai.

Ab local name x new object ko refer karta hai.

Original name n ab bhi 7 ko refer kar raha hai.

Isliye:

Inside = 14
Outside = 7

IMPORTANT CONCEPT:

Python mein arguments pass by assignment hote hain.

Function ke parameter ko argument wale object ka reference milta hai.

Parameter ek local name hota hai.

Reassignment of local name automatically caller ke variable ko change nahi karta.

NOTE:

Mutable objects jaise lists ka behaviour next class mein detail mein samjhenge.

PART 8: LAMBDA FUNCTIONS
============================================================

24. LAMBDA KYA HOTA HAI?

Lambda Python mein small anonymous function create karne ka short syntax hai.

Anonymous ka matlab: function ka koi explicitly defined naam nahi hota.

Normal function:

def square(n):
    return n * n


print(square(5))

Lambda equivalent:

square = lambda n: n * n

print(square(5))

Output:

25

Syntax:

lambda parameters: expression

Explanation:

lambda:
Anonymous function create karta hai.

n:
Parameter.

n * n:
Expression jiska result automatically return hota hai.

IMPORTANT DIFFERENCES:

Normal def:
Multiple statements likh sakte hain.
Function ko meaningful naam de sakte hain.
Complex logic ke liye useful.

Lambda:
Single expression allowed hota hai.
Explicit return statement nahi likhte.
Expression ka result automatically return hota hai.
Small temporary functions ke liye useful.

------------------------------------------------------------
26. LAMBDA WITH SORTED()
------------------------------------------------------------

Humne sorted() function pehle use kiya hai.

Example:

words = ["banana", "fig", "apple"]

print(sorted(words, key=len))

Output:

['fig', 'apple', 'banana']

Explanation:

key=len ka matlab:

Python har word ki length calculate karega aur length ke basis par sorting karega.

banana = 6
fig = 3
apple = 5

Sorted lengths:

3, 5, 6

Output:

['fig', 'apple', 'banana']

Ab lambda ke saath:

words = ["banana", "fig", "apple"]

result = sorted(words, key=lambda w: len(w))

print(result)

Output:

['fig', 'apple', 'banana']

Explanation:

lambda w: len(w)

Har word ko input lega aur uski length return karega.

sorted() function har element ke liye key function call karta hai.

Returned values ke basis par original elements sort hote hain.

IMPORTANT:

Function ko argument ke form mein pass kar sakte hain because functions are objects.

------------------------------------------------------------
27. DEF VS LAMBDA
------------------------------------------------------------

Normal function:

def last_char(word):
    return word[-1]


words = ["apple", "banana", "fig"]

print(sorted(words, key=last_char))

Lambda:

words = ["apple", "banana", "fig"]

print(sorted(words, key=lambda w: w[-1]))

Output:

['banana', 'apple', 'fig']

Dono ka purpose same hai.

Use def when:
- Logic complex ho.
- Multiple statements hon.
- Function reuse karna ho.
- Meaningful function name chahiye.

Use lambda when:
- Logic very small ho.
- Single expression ho.
- Temporary function chahiye.
